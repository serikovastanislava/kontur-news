# Контур

## Backend / автоматическая лента

В проекте есть автоматический сбор новостей:

- БНК Коми — HTML-парсинг, потому что `/rss/` отдаёт 404;
- РИА Новости — RSS;
- Российская Газета — RSS;
- ИА «Панорама» — HTML-парсинг;
- каждая 20-я позиция общей ленты — материал «Панорамы»;
- у «Панорамы» удаляется фрагмент `Рейтинг: <число>` из заголовка;
- для новых материалов запрашивается полный текст статьи, если источник его отдаёт;
- автор берётся из страницы источника, а не заменяется названием источника;
- краткое резюме сохраняется отдельно для блока «Коротко»;
- обложки выбираются из Openverse (открыто лицензируемые изображения) по теме статьи, а не из `src/assets`;
- основной баннер выбирается по прозрачной формуле из свежести, контентной значимости и собственных просмотров «Контура»;
- React обновляет ленту без перезагрузки страницы.

### Локальный запуск

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py check
python manage.py parse_news
python manage.py runserver
```

При `runserver` локальный scheduler запускает парсер каждые 60 секунд.

### Обновление уже сохранённых материалов

После обновления проекта рекомендуется один раз выполнить:

```bash
python manage.py migrate
python manage.py backfill_news
python manage.py refresh_news_images --all
```

### Docker

`docker-compose.yml` содержит отдельный сервис `parser`, который выполняет:

```bash
python manage.py parse_news --loop --interval 60
```

Backend на Gunicorn не запускает свой scheduler, чтобы не создавать несколько параллельных парсеров.

## Важно про полные тексты

Сбор и повторная публикация полного текста стороннего материала должны соответствовать условиям конкретного источника и применимому праву. Технически парсер пытается получить полный текст только из доступной публичной HTML-разметки; если источник отдаёт только краткий текст или блокирует запрос, сохраняется доступный материал и ссылка на оригинал.

## Исправления интерфейса новостей

- «Коротко» показывает сокращённые заголовки, а не повторяет текст статьи.
- Выпадающие меню тем в верхнем меню используют реальные статьи из API, сортируют их по дате и показывают несколько материалов.
- Поиск ищет по реальным новостям из Django API: заголовок, сокращённый заголовок, рубрика, источник, автор и текст.
- Изображения при парсинге выбираются с учётом уже использованных URL, чтобы одна картинка не назначалась всем материалам.
- Для уже загруженной базы можно выполнить `python manage.py refresh_news_images --all`.
- Основная лента сохраняет правило Панорамы: каждая 20-я позиция — материал Панорамы, если такие материалы есть.
